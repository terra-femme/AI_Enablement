# Lesson 6 — Wrap + 3 Habits + Q&A
**Time:** 5 min · **Core message:** *Three habits to start Monday.*

## Objective
Send the room out with a tiny, memorable action set — and open the floor.

## The 3 habits (the entire session, distilled)
1. **Verify before you send.** It can be confidently wrong; you're accountable.
2. **The stranger test.** Don't paste what you couldn't email a stranger; use only approved tools.
3. **Save it home.** Projects for work-in-progress, the team drive for finished work.

> Put these 3 on the leave-behind one-pager and the final slide. Repeat them out loud.

## Closing script (30 sec)
> "You don't have to be an expert. If you do these three things, you're already using AI more safely and effectively than most people out there. Start with one real task this week."

## Q&A (5+ min — the most valuable part)
- Open with: *"What's the one thing you're still unsure about?"*
- Use the prepared answers in `qa_common-questions.md`.
- **If you don't know:** say *"Great question — I'll confirm and follow up,"* write it down, and actually follow up. (See `../presenter/presenter-best-practices.md` — this builds trust, it doesn't lose it.)

## Leave-behind checklist
- [ ] 1-pager: the 3 habits
- [ ] The AI Acceptable Use Policy (`../acceptable-use-policy-template.md`)
- [ ] Where to ask questions / report issues: [CONTACT / CHANNEL]
- [ ] Optional: link to the next session (role-specific playbook)

## Measure it (so you can prove value)
- Quick 3-question exit poll: confidence before/after (1–5), "will you change one habit?" (y/n), "what topic next?"
- This data is your **case study** and your pitch to the next client.
