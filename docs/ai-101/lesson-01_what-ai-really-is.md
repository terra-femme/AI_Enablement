# Lesson 1 — What AI Actually Is
**Time:** 8 min · **Core message:** *It's a brilliant new intern, not a live, all-knowing oracle.*

## Objective
The room leaves understanding three things: AI predicts language, it has a knowledge cutoff, and it can be confidently wrong.

## Demo first (2 min)
Ask the tool a simple work task ("draft a polite reply declining this meeting") — show it works and is fast. *Then* ask it something it might get wrong (a very recent event or an obscure fact) to show a limit. Let the contrast land before explaining.

## The 3 ideas (rule of 3)
1. **It predicts language, it doesn't "know" facts.** It's trained to produce the most likely helpful text — incredibly useful, but not a database of truth.
2. **It has a knowledge cutoff.** It learned from data up to a point in time. It is *not* live unless a tool explicitly gives it web access.
3. **It can hallucinate.** It can state wrong things — names, numbers, sources — with total confidence.

## The anchor analogy
> **AI is a brilliant new intern.** Fast, well-read, eager. But it's been on a desert island since its training cutoff, it sometimes makes things up to sound helpful, and you'd never let it send work to a client unchecked.

## Myths to kill (call them out by name)
- ❌ "It's live / it's connected to the internet by default." → Only if a tool adds that.
- ❌ "It's a search engine." → It reasons and writes; it doesn't look things up unless told.
- ❌ "If it sounds confident, it's right." → Confidence ≠ accuracy.

## Talking points / script beats
- "How many of you thought it was pulling live info? *(hands)* Totally common — and exactly why we're here."
- "Knowing this one thing — that it can be confidently wrong — makes you safer than most people using it."

## Common stumble (and the fix)
- Someone says "but mine looked something up yesterday." → Great teaching moment: *some* tools/modes add live web or document access (that's a feature that's turned on); the base model itself isn't live. Don't over-explain — just plant "it depends if that feature is on."

## So what / now what
**Now what:** treat every factual claim as "trust but verify" (sets up Lesson 4).
